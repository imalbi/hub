# Ui (web)

- `ui/liquid-tabs.tsx` is the Hairline `liquid-tabs` item used by `ZoneTabs`: surface-tension highlight, no panels of its own (the page renders the `tabpanel`, the URL decides the tab), `id` shared with the panel, tokens instead of Tailwind sizes, `onKeyDown` on each tab (the lint rule wants focusable elements to own key handlers), and `NumberRoll` count support. Size `md`. `ui/tabs.tsx` is kept for any static tabs.
- Vendored by hand for the Ricerca lavoro zone (16g2), not through the CLI: it targets `src/components/`, duplicates `text-morph` and `ui-interaction-motion`, and adds `lucide-react`, which the popover and dropdown items declare without importing. Upstream headers stay, imports carry the extension, spacing/type/colors/radii map to tokens, icons are Phosphor, and every visible or accessible English default is a prop the caller fills in Italian. Our `ui-interaction-motion.ts` and `text-morph.tsx` differ from upstream only by the lint adaptations of the first vendoring (07b); exports are identical.
  - `ui/search-input.tsx` (with `input.tsx`, `field.tsx`): list search box. `shortcut` defaults to `/` (Ctrl K is the palette's); `clearLabel` names the clear button; `Input` is `sm` (2rem) or `md` (`h-touch`).
  - `ui/select.tsx` + `pill-select.tsx`: a themable listbox in a portal, never the browser dropdown. `Select` is the labelled form field, `PillSelect` the bare pill for toolbars (`size` `md` matches `h-touch` controls). The list grows to its longest label; its rows are 2.25rem, the list at most 17.5rem (rem constants in the file, scaled for the desk). The check is the component's own drawn stroke, kept on purpose. Inside a modal `<dialog>` (the palette's form pages, the theme editor) the list portals into that dialog instead of the body, because a modal makes the rest of the page inert and paints it under the top layer; `Select` has no form value, so a form keeps the picks in state. A native `<select>` stays only on the deck theme list (the iOS picker, on purpose).
  - `ui/popover.tsx` + `floating.ts`: panel anchored to a trigger, `size` sm/md/lg (`--spacing-popover-*`), solid `bg-background` (only the nav and player are glass). `useDismiss` ignores presses inside any `[data-floating-layer]`; the select's portalled list sets it, so picking a value inside a popover does not close the popover (a Lavoro spec row fails without it). `THEME_TOKENS` is our variable list, not shadcn's.
  - `ui/dialog.tsx` + `modal.ts`: native `<dialog>` with `showModal`. `size` sm/md/lg/xl (`--spacing-dialog-*`, 25/32.5/48/56rem), `closeLabel`. It plays an exit after `open` turns false, so a dialog driven by the URL must keep the last item in state while it leaves (Lavoro's `shownJob`).
  - `ui/tooltip.tsx`: hover and keyboard focus only, never on touch; it adds `aria-describedby` only, so an icon button keeps its `aria-label`. Wrapping a `Popover` in a `Tooltip` works (the trigger stays the popover's own button). Inside a modal `<dialog>` it portals into that dialog, chosen in `show` before it mounts: a surface on the body sits under the top layer, so no z-index lifts it (the Lavoro detail tooltips were hidden behind the dialog). `Popover` still portals to the body, so one opened inside a dialog would hide the same way.
  - `ui/slider.tsx`: one value or a range. `onValueChange` fires while dragging, `onValueCommit` once on release or key up (the volume and Luci sliders keep a draft and write there). Never disable a slider while its write is pending: a disabled input loses focus, so the arrows stop after a click (23e). The single-thumb keydown sets `active` again, since a pointer release clears it while focus stays and `end` commits only when active (fixed 2026-11-11, `music.spec.ts`). The bubble and thumb use tokens; timings stay upstream.
  - `ui/kbd.tsx` (`Kbd`, used by the palette), `ui/checkbox.tsx` and `ui/expanding-button-group.tsx`: vendored and mapped to tokens (danger and success colors, rem boxes, type roles); the checkbox and the button group are not wired yet. A checkbox never confirms a `danger` action; that is the hold.
  - `ui/switch.tsx`: sizes in rem; a promise from `onCheckedChange` shows the pending thumb, a rejection shakes it back.
  - `ui/textarea.tsx`, `ui/tag-input.tsx` (+ `use-token-flip.ts`), `ui/password-input.tsx`, `ui/multi-select.tsx`: fetched with the shadcn CLI into a scratch folder (it targets `src/components/` and would duplicate `field`, `input`, `floating`, `ui-interaction-motion`, `number-roll`, `text-morph`, `icon-morph`) and copied in alone, for Impostazioni. Same adaptation as before: `.ts(x)` imports, Phosphor (`EyeIcon`, `EyeSlashIcon`) in place of lucide, stock sizes and colors mapped to tokens (red/amber/emerald became `danger`/`muted-foreground`/`success`, `bg-popover` `bg-background`; the other numeric sizes stay explicit rem values), every English default a prop: `TagInput` takes a required `copy` (`TagInputCopy`: every sentence it shows or announces) and `label`, `MultiSelect` a `copy`, `PasswordInput` `showLabel`, `hideLabel`, `capsLockHint`. Targeted `oxlint-disable` comments (with reasons, `{/* */}` form inside JSX children) cover the combobox roles the lint wants as native tags. Remaining warnings are upstream's.
  - `ui/split-button.tsx`: copied by hand from the Hairline MCP source (the CLI would overwrite `text-morph`/`ui-interaction-motion` and add `lucide-react`). Phosphor caret, `h-touch` only (no size prop), `danger` tokens, panel geometry in rem read at open, `menuLabel` required (Italian). The wrapper is `isolate`, so it raises itself to `z-50` while the menu is mounted: otherwise the menu opened under a later list and its items could not be clicked (Lavoro import e2e). Lavoro's Raccogli uses it.
  - `ui/stepper-input.tsx` and `ui/json-inspector.tsx` + `json-tree.ts`: copied by hand from the Hairline MCP source for Impostazioni (numeric fields; the saved-versus-draft diff), reusing our `number-roll`, `status-button`, `text-morph`, `field` (`fieldSurface`). Phosphor icons, tokens (emerald/red/amber became `success`/`danger`/`muted-foreground`, the syntax palette `foreground`/`accent`), `h-touch` and `text-body sm:text-label` like `Input` md. `StepperInput` is controlled only (`value: number | undefined`, undefined = unset: `placeholder`, the first step lands on `min` or 0), named by `label` or `labelledBy`, with required `decreaseLabel`/`increaseLabel`. `JsonInspector` takes a required `copy` (`JsonInspectorCopy`: every sentence it shows or announces). `ui-fade-in` keyframe lives in `index.css`.
- `ui/empty-state.tsx` + `ui/empty-state-scenes.ts`: adds three Hub domain scenes (`music` turntable, `calendar`, `notes`) alongside Hairline's five (`inbox`, `search`, `done`, `offline`, `chart`), plus `variant?: 'default' | 'compact' | 'inline'` and `icon` (Phosphor glyph sized with Hub icon tokens). All variants preserve `<h3>` for heading queries and expose `data-empty-variant` (plus `data-empty-scene` on default without custom `illustration`); `compact` and `inline` use Hub spacing/type tokens only.
