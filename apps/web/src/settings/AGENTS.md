# Settings (web)

- `/desk/settings` is not a `ZonePage`: `routes/desk.settings.tsx` renders `settings/settings-layout.tsx` (the list on the left, the page of the chosen entry beside it), with `desk.settings.index.tsx` (redirects to Aspetto with `replace`, step 63), `desk.settings.appearance.tsx` and `desk.settings.$module.tsx` (`settings/module-page.tsx`) nested. The rail and the header title use `zoneAt(pathname, zones)`, which matches a path under a zone (`/desk/settings/lavoro` is Impostazioni, the overview never matches by prefix). The settings page uses loopback-only procedures; `settings.config`, `save` and `restore` additionally allow agent clients, never paired devices.
- Module page (step 33): header with the back link, name, kind, the switch and Annulla/Salva e riavvia (`ActionButton`); then a 7/5 grid: Essenziale (`module-form.tsx`: root fields, then one section per nested object, heading from its `title`, dashed separators, narrow fields two per row) and a sticky aside with Modifiche (`changes-panel.tsx`, Hairline `JsonInspector` diff of saved vs draft, only while dirty) and Avanzate (`advanced-panel.tsx`, a disclosure list of JSON blocks; closed blocks stay mounted so half-typed JSON survives). `settings/schema-fields.ts` (`buildForm`, pure, unit tested) maps JSON Schema to field kinds: text, multiline, number (`StepperInput`), boolean, choice/multi (options `{ value, label }` from `optionLabels`, numbers stay numbers), words, secret, numberMap/wordsMap (`map-rows.tsx`), rows (`object-rows.tsx`, a list of flat objects); the rest is a block. Field anatomy (`field-shell.tsx`): label as accessible name, control, one caption with the description plus "Predefinito: X" or "Non impostato" wired as `aria-describedby`. Map rows keep their own state; an empty or duplicate key and a broken JSON block both enter `blocked` and hold Salva. The draft is `null` until touched and never gets defaults written into it. Server issues come back as `{ path, message }` and show under the matching field or block, or at the top.
- Labels are the one exception to Paraglide: a module's Italian `title`, `description`, `unit` and `optionLabels` live in its zod schema meta (`docs/modules.md`), so private words stay in the private module; the shell's own words (Essenziale, Salva, Predefinito) stay in Paraglide.
- Secrets (`settings/secret-field.tsx`): the value never reaches the page; the field says "impostata" or "non impostata" and `Sostituisci` opens a `PasswordInput`; `{ set: true }` in the draft means "keep".
- Restart (`settings/restart.ts`, `restart-screen.tsx` in `DeskShell`): `beginRestart(queryClient)` after an answer with `restarting: true`; the phase is `waiting` until the socket drops, `down` while it retries, `done` when it is back (every query is invalidated, the page never reloads) and then idle after 5 s; it gives up after 15 s if the socket never dropped.
- Impostazioni > Generale > Sistema e agenti (`settings/core-page.tsx`, route `desk.settings.core.tsx`): the core `mcp`, `jobs`, `backup` and `assistant` sections through `settings.core`/`saveCore` with `ModuleForm` and the same restart flow; `server` is never on it.
- Copy for private modules' labels in the list: `moduleLabel` (Paraglide for public names, the zone label of a module UI, else the capitalised name).
- `moduleLabel` (`settings/module-label.ts`) falls back to the module UI's `copy.title` before the capitalised name, so a private module without messages (AirPlay, Luci) is named by its own copy.
- Impostazioni is a surface: `SettingsLayout` = `PageSurface fill` (no spacer row, 47c) with the list as an inner panel (`data-panel`, rows hover/active `bg-surface`, one step lighter than `bg-muted`) and the page in a `relative overflow-y-auto` section, so the page scrolls on its own. `PageSurface`'s `className` goes to its body (`flex-row gap-lg` here). Sticky headers on settings pages are `bg-surface`, not `bg-background`.
