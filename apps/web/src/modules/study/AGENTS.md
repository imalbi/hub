# Study (web)

- Studio adds `piano` and `piani` sections to built-in `study`; `use-study.ts` uses the shared module WebSocket and scoped TanStack options. Piano loads day bodies only for open groups. Piano and Piani follow the Studio mockup (plan 40): day rows and week groups are disclosure buttons with `aria-expanded` (not `<details>`), subject shades come from `subjectShade` in `use-study.ts` (foreground opacities, never `surface-raised`, which is dark in paper). The Hairline `ButtonGroup` drew no selected fill in a small filter row (the active label went dark on dark), so filters are plain pressed-state pills in a `fieldset`. With several active plans (decision 15) `studySubjects` labels each subject by its plan (`<plan>:<subject>` keys), Piano groups by week instead of phase and opens the first group when the current day is filtered out. Tailwind `max-w-md` resolves to this project’s 1rem spacing token, so use named width tokens such as `max-w-dialog-md` for forms.
- `modules/study/day-body.tsx` is shared by Piano and Oggi; only Oggi passes a tick handler. Oggi's note and step drafts retain failed edits across tab navigation, and the index supplies the selected current day across all active plans.
- Study's instrument Pomodoro passes the current day tag on start (`pomodoro.startTagged`) and shows the day's minutes in its footer; Piano rows show studied minutes only above zero, beside the planned estimate. Oggi polls `focusMinutes` every 3 s (a `shortcut:` comment), Piano reads it on mount; `material.tsx` opens an authenticated PDF as a blob in a synchronously opened tab so paired devices can display it at `#page=N`. Library downloads use the attachment route.
- Studio Ripasso (`modules/study/review.tsx`) and the inline error form (`error-form.tsx`, shared by Oggi and Ripasso): the form lives in the panel, no dialog. Rows are dashed-separated, filters are `aria-pressed` pills like Piano. Visual baselines seed their data in `study.visual.spec.ts` (`seedReview`, undone in `finally`) so the other Studio baselines keep their single-step days.
- Study `day-body.tsx` (Oggi and Piano): Oggi numbers steps and highlights the first open step with a named error button; the other error buttons remain available on hover and keyboard focus. Never put a path or any unbreakable string in a `flex` row without `min-w-0`: it pushed the `ml-auto` button over the next column (step 43b). "Da aprire" = day `materials` then step files, deduplicated by path. `RegistryButton` `name` is the accessible name when it must say more than the label; `TextMorph` duplicates button text, so e2e reads `aria-label`, not `toHaveText`.
