# System (web)

- Widgets `controls` (Comandi: Blocca, Chat, Lettore as buttons; Sospendi, Riavvia, Spegni as outline `HoldButton`s; wide or large) and `power` (Consumo: watts as the big figure, today's kWh above; small or medium), with `server`; the Sistema page (`modules/system/page.tsx`, board "Righe" of step 34) is two inner panels of dashed rows: "Questo PC" (Blocca, Chat, Lettore, Webcam, one row per `system.monitors` entry, then `ModuleUI.systemRows`, then the three holds at the foot) and "Audio" (`modules/audio/system-rows.tsx`: output switch, volume, mute, microphone; Consumo and Server as two figures at the foot, Server alone when `powerstatDir` is unset). Rows are direct children of a list that draws a dashed line above each child (`[&>*]:border-t`), so a row that renders null leaves no gap; `systemRows` takes `DeviceRow`s like `deviceRows`. The Webcam row (`webcam.tsx`) opens `getUserMedia` only while its dialog is open: the effect cleanup stops every track on close, unmount and route change, a late-resolving request is stopped at once, and the microphone level is written to the DOM from an animation frame. Monitor tiles (`MonitorTiles`, one tile per entry, icon weight fill when on) are on the deck Sistema page, not Scrivania: Scrivania already holds 12 tiles with AirPlay and the grid stops at 12. e2e runs Chromium with its fake media device flags (`playwright.config.ts`, desk project). Deck tiles in `modules/system/deck-tile.tsx`; the consumption tile is not a button. `power-text.ts` formats both (Italian decimals).
