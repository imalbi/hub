# Media (web)

- Desk shell owns MediaProvider: one media subscription and a typed artwork query cached by artKey. Only a matching successful image earns infinite stale time; null/mismatched replies throw for two bounded retries and remain eligible for ordinary query recovery on remount/focus/reconnect. The raw artwork URL is never in the browser. MediaPanel/Backdrop/PlayerBar share it. The floating activity is the ball (`shell/activity.tsx`, step 47c, see "Activity ball" in `src/shell/AGENTS.md`). DeskRail keeps Link semantics and uses the Hairline motion primitive for a single transform-based indicator; routes, names and number shortcuts are unchanged.
- `modules/media/deck-player.tsx`: the desk player pill at phone size (glass, cover, title, previous/play-pause/next) below the pages on every page, shown while a player has a track (playing or paused, so a paused track can be resumed), hidden with no player or stopped. The deck sits inside `MediaProvider`.
- Media page tab is `fill` and `float`: Musica has a library column with search and a content view whose lists scroll inside the surface.
- `modules/media/player-bar.tsx` (`PlayerBar`) is the player bar; `audio-button.tsx` is the one audio popover (output switch plus, when Musica is on, the music volume from `music/volume.ts`). Do not flip a button's `type` between `button` and `submit` on click (React flips it before the default action, the click then submits): render two elements.
- `modules/media/widget.tsx`: `small` shows status in header, cover, title + artist, single play/pause button, and stretched `/desk/media` link; `medium`/`wide` show output header link, tall square cover left, seek bar + compact transport right; `large` shows `w-1/3` square cover, seek with elapsed/total times, centered compact transport, and `useIsOn()('music')`-gated `Prossimi` capped at 3 rows.
