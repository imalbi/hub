# Mail (web)

- `modules/mail/use-mail.ts`: the module's `create` returns an empty router when unconfigured, so `AppRouter['mail']` infers as empty; the client is `createRouterClient<MailRouter>('mail')` (`lib/module-client.ts`, the same transport as `createModuleClient`) typed from `createMailRouter`. Availability is `mail.accounts` (answered from the config, no himalaya call, `staleTime: Infinity`), asked by `useIsOn` on every page: never use `mail.state` for that, it reads every inbox.
- Posta page (step 39, board `PostaB`): `posta-section.tsx` holds the state (account, filter, selection, compose); the account `ButtonGroup` (Tutte first, only with two or more accounts) and Scrivi are portalled into the zone's tab bar through `TabBarActions` (`shell/header-slot.tsx`; `ZoneTabs` renders the slot after the tabs and `PageSurface`'s bar is full width). The list is `useInfiniteQuery` over `mail.inbox`; `inbox-list.tsx` reads the next page when its end row (the sentinel) scrolls into view, shows "Non ci sono altre mail" at the end, and its scroller is keyed by account and filter so a new search starts at the top. Aggiorna trims the cache to the first page, scrolls up and refetches. `filters.tsx`: Filtri is the house `Popover` (`size="xl"`), Dopo il is a field read by `lib/parse-day.ts` with direction `past` plus the `Calendar` (`compact`, `initial`, remounted by month when a typed day changes it); active filters are `Chip`s. Reply and compose (`reply-form.tsx`, `compose.tsx`) use `TagInput` with `settings/field-copy.ts`, a hold (`HoldButton`) that throws before any request on a form problem, and one Italian error line. Archive shows a toast with Annulla (local to Posta).
- The deck uses only the protected state subscription and displays counts; `list`, `search`, `read` and `threads` are PC-only. A failed account makes the total unavailable; a capped account makes it a lower bound.
- Mail's on/off is `mailIsOn` (`lib/mail-on.ts`): on before the first answer, then only with accounts. A failed `mail.accounts` that another page mounts again (Lavoro's Candidature) goes back to `pending` with no data while it refetches; counting that as on flashed Messaggi into the rail and moved the centred rail up by one icon (2026-11-10).
- Palette source (step 64): `records.ts` (`mailMessages`, id `mail-messages`) calls `mail.searchRecords` and links to `/desk/messaggi?tab=mail&subject=<subject>&message=<account>:<id>` (`search.ts`: `postaSearch` is the route's `validateSearch`, `postaHref` builds it). `PostaSection` reads `subject` and `message` from the URL in an effect: it picks "Tutte", sets the subject filter and selects the message, so the row is in the loaded page whenever the search finds it. A link with only `subject` (Vedi tutti) just searches.
