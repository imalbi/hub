# Notes (web)

- Post-its (step 38, `modules/notes/`): the desk shell mounts `NoteCapture` (a `useModal` dialog, not `Dialog`, so the card has no title row) and `NoteUndoToast`, and binds plain `n` (skipped in fields, with modifiers, and while any `dialog[open]` is on screen); `store.ts` is the small external store for "capture open" and the last removed post-it. Oggi's middle column is the new `ModuleUI.todayColumn` slot (`weather/today-widget.tsx` renders it between the date column and the weather; the column scrolls inside with `mt-auto`, so a 1-row Oggi shows the newest cards at the bottom); the Today widget also offers `full`. The widget is offered in Panoramica but not in the default board. The day picker is the browser's own calendar (a hidden `input[type=date]` opened with `showPicker`), not a drawn one. `notes.visual.spec.ts` swaps the `notes.onOpen` subscription data by request id (the client batches requests into arrays).
