# Notes (web)

- Post-its (step 38, `modules/notes/`): the desk shell mounts `NoteCapture` (a `useModal` dialog, not `Dialog`, so the card has no title row) and `NoteUndoToast`, and binds plain `n` (skipped in fields, with modifiers, and while any `dialog[open]` is on screen); `store.ts` is the small external store for "capture open" and the last removed post-it. Oggi shows the post-its through `ModuleUI.todayColumn` (`notes/today.tsx`, `NotesColumn({ day, variant, max })`, step 66): a count in Medio, a titled column in Largo, a titled grid two per row in Grande, a bare stack per day in Esteso, where tomorrow's ends with its count and Aggiungi (`openCapture('tomorrow')` preselects Domani). Cards are one line, the origin muted after the text, cut by `max` with "e altre N": never scrolled. The widget is offered in Panoramica but not in the default board. The day picker is the browser's own calendar (a hidden `input[type=date]` opened with `showPicker`), not a drawn one. `notes.visual.spec.ts` swaps the `notes.onOpen` subscription data by request id (the client batches requests into arrays).
