# Devices (web)

- The Dispositivi QR is a `Dialog` opened by "Mostra QR" (`devices/qr-section.tsx`), mounted only when `devices.deckUrl` is non-null; the dialog mounts its body only while open, so the QR img does not exist in the DOM when closed.
- `PairingScreen`: code input (`inputmode="numeric"`, `autocomplete="one-time-code"`, 6 digits), device name prefilled with `pairing_default_name`, one-line hint to install first when `navigator.standalone` is not true (on iOS the Home screen app does not share `localStorage` with Safari, so a token stored from Safari is lost).
- `src/modules/devices/desk-panel.tsx` (`DevicesBoard`) is the Dispositivi page (mockup B of step 35) and, stacked, the large Panoramica widget: left 4 columns "Collega un telefono" (step 1 the QR dialog, or one line saying the deck needs the LAN when `devices.deckUrl` is null; step 2 Genera codice with the code in `text-display` as an `<output>` with a name, and its countdown) over `ServicesPanel` ("Collegati a questo PC", the module `deviceRows`); right 8 columns "Chi ha accesso" with "Telefoni e tablet" (revoke with `HoldButton`) and `agents-section.tsx` (Copia comando with the fixed loopback `claude mcp add` line, the "Su questo PC" row from `agents.localCalls`, token agents with Revoca, the token form in a closed `<details>` "Agent da un altro PC"). The cells carry `col-span-4`/`col-span-8` and the board is a fragment: in a grid they lay out, in the widget's flex column they stack. The clock is `useNow(expiresAt ?? 'clock')`: on the code's own seconds while one is shown, so a fresh code reads 120 s, never 121. The device list refetches every 2 s only while a code is on screen, the one place polling beats a subscription. Calls of an agent show on demand (button "Chiamate di <name>"); tRPC has no transformer, so `createdAt` of a call row arrives as an ISO string (devices return numbers).
- Deck QR (`modules/devices/qr.ts`, `qr-section.tsx`): `uqr` `encode()` matrix drawn as one `<path>` in our own `<svg>`. The light square is fixed white and the modules black on purpose: a theme-inverted QR (light on dark) is not read by every scanner. Size token `--spacing-qr`. The URL comes from the loopback-only `devices.deckUrl` query (`deckUrl` in `apps/server/src/core/origin.ts`: first non-loopback entry of `server.allowedOrigins` + `/deck`, null otherwise).
- Dispositivi: `DevicesBoard fill` (the page) is a `grid-cols-12 grid-rows-1` row at surface height, left `col-span-5`, right panel `col-span-7` scrolling inside; the widget calls it without `fill` and stacks. Count text is a plural message with two selectors (`devices_access_count`; the inlang message-format key for several selectors is `"a=one, b=*"`, comma separated, a space makes only the first selector count). `agents.localCallsToday` (server count since local midnight) feeds "N chiamate oggi, ultima ..." because `localCalls` stops at 20 rows.
