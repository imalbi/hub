# Shell (web)

- The activity ball's countdown ticks inside its button, which is not a live region: a clock tick must not be announced, so do not wrap the time in `aria-live`. Its accessible name lists what runs and is read when the ball is focused. (`components/ui/live-activity.tsx` stays vendored; nothing imports it.)
- Pages: `shell/pages.ts` defines Scrivania and Sistema. Scrivania holds the workspace, audio, Pomodoro, Posta and lock tiles; AirPlay follows Pomodoro when present. Sistema starts with monitors, then Luce and consumption, then a new row of three holds and the theme select. `shell/deck-pages.tsx` owns the shared player, the header's running Pomodoro and job indicators, scroll-snap pages and remembered `hub.deck.page`; an unknown saved page falls back to Scrivania. Off-screen pages are inert and aria-hidden. Tiles use three columns and rows at least 6.5rem high. Unpositioned module tiles go together to the last page with room for all of them (12 rendered tiles, counting each monitor), before Sistema's holds, which stay last (board D1); `pages.ts` contains the pure placement and `deck-page-config.ts` supplies the live count.

- `/deck` renders `PairingScreen` until a token is stored, and the tiles after; it never shows tiles to an unpaired browser, even on the PC. Both sit in `DeckFrame` (`src/shell/deck-frame.tsx`): the safe-area padding (`pt-safe-top`, `pr-safe-right`, `pb-safe-bottom`, `pl-safe-left`, tokens over `env(safe-area-inset-*)`, zero outside the iPhone) outside, the page padding and the header inside.
- PWA without a service worker: `public/manifest.webmanifest` (standalone, `start_url` `/deck`), `public/apple-touch-icon.png` and `index.html` (`viewport-fit=cover`, `apple-mobile-web-app-*`). The ink background `#070707` appears in the manifest and `theme-color` because neither can read CSS variables; it is `--background` of the ink theme, change them together. The icon is a **placeholder** drawn in `public/icon.svg`: `rsvg-convert -w 180 -h 180 public/icon.svg -o public/apple-touch-icon.png`.
- The palette is the Hairline `command-palette` item vendored as `components/ui/command-palette.tsx` (step 20, replacing cmdk; owner, 2026-11-10) and mounted by `shell/command-palette.tsx` (`DeskCommandPalette`, desk only) in the rail (`shell/rail.tsx`: ONE glass pill, vertically centred with `inset-y-0 my-auto h-fit` and no transform, so nothing gets a new containing block; top to bottom the trigger on `bg-muted`, "Ctrl K" under it, a hairline, the zone links with the sliding `data-rail-indicator` in their own `relative` box so its `index * (touch + xs)` offset needs no correction, a hairline, the status dot, an `output` named "Connesso" or "Connessione persa"): a round magnifier button (`trigger="rail"` on the vendored component), accessible name "Cerca o esegui, scorciatoia Ctrl K". A click or Ctrl+K opens the palette centred near the top of the screen (not hanging from the button: `hang` is false in rail mode); only the grow and fold start from and land on the rail button. Escape folds it back. There is no bottom-right button and no `pb-palette-clear`. The shell builds `CommandItem`s: a **Vai a** group (every rail zone, `onSelect` navigates with the router, never a full load) above **Azioni** (the registry, recent first, Italian labels, the English description as a keyword, the zone label as `meta`). An action with no input runs from `onSelect` (a promise: spinner, check, fold); an action with input, an unsupported schema or `danger` has a `view` page (the chip in the field, Escape or Backspace goes back) that renders `PaletteForm`. Copy is a `copy` prop filled from Paraglide; `emptyText` says loading, the generic error or "Nessun risultato per ..." (a `role="status"` line), and the footer line (`aria-live`) shows pending or the generic failure of a row, never the server message.
- **Records in the palette (step 64).** `useRecordItems` in `shell/command-palette.tsx` turns `ModuleUI.records` answers into `CommandItem`s (`always: true`: the server already matched, so the palette's own filter never hides them; `group` is the source label; `groupAside` is the count and "Vedi tutti in <zona>", the zone read with `zoneAt(allHref path)`; `detail` is the muted second line, `badges` outline `Badge`s). The group order lives in ONE place, the `items` array there (records in module order, Vai a, Azioni), and `rank` in the vendored file sorts by group first appearance and only then by score, so a later row ("Chiedi a Hub", step 72) is appended at the end of that array. A query with rows elsewhere and none under Azioni keeps the heading with `nessuna per “<query>”` (`emptyGroup`), except when the assistant row is shown last. Registry actions with a required field `paletteFields` cannot draw are not listed (step 64 reversed step 24); an optional one is left out of the form and the action stays (step 71: `notes.add`'s `about` hid "Aggiungi post-it"). Record rows with a `detail` are `3.5rem` tall (`DETAIL_ROW`) and the list may grow to 36rem instead of 22 when one is shown. `onQueryChange` reports every query (and '' on a fresh start). `hub.palette.recent` still holds action paths only: no record text is stored.
- Edits to the vendored file, all deliberate: a native modal `<dialog>` instead of the fixed div (focus trap, inert page, and `Select` portals into the closest `dialog`); every size in rem (the desk root is 150%, the unit is read when it opens, never during render); Phosphor icons and our `Kbd`; `view` pages and `meta`/`note` on items; no `href`; Escape goes back or closes and never clears the query (Escape is handled in capture so a hold cannot swallow it, and in `onCancel` for when focus is on the body, as after a submitted form disables its field); the input is focused as soon as the dialog is shown (a `fill` right after the hotkey must land) and again whenever a page is left, but never when the grow ends while a page is open (Enter before the grow ended opened the page, then the end of the grow stole its focus back: the hold had no focus about half the time, `palette-regressions.spec.ts`); a `session` counter makes a late answer from an old session do nothing, so a slow action cannot close a newer form; the keep-in-view effect leaves the list at the top for the first row and while the list is still 0 high (on open it saw every row below the fold, scrolled, and the first group heading stayed hidden: real data at 4K, step 64 review; headless runs never reproduced it). Under reduced motion the global desk CSS already kills transitions, so the component's own branch is guarded by a script animation (the page slide), which the e2e check counts.
- The palette mounts over protected `registry.list` (loaded on open); it runs only returned mutation paths through the existing authenticated tRPC client, including private modules, then invalidates every query. `palette-input.ts` admits flat primitive/enum schemas only; nested/opaque schemas stay listed and open a page that says so. `palette-form.tsx` adds `confirmed: true` only after HoldButton confirms, never from a checkbox. Recent storage (`hub.palette.recent`) contains paths only.
- Panoramica is the only phone-style board (`routes/desk.index.tsx` renders `WidgetBoard` inside `PageSurface`; the default layout is `defaultLayout` in `shell/widgets.ts`) and it offers every widget, built-in and from modules, including those that also appear on a page. Pages are not boards (see "Desk zones and panels"). The board is `shell/widget-board.tsx`, react-grid-layout 2.3.0, chosen over @dnd-kit + motion and gridstack. Sizes in `lib/widget-size.ts`: Piccolo 3x1, Medio 6x1, Grande 6x2, Largo 12x1, Esteso 12x2 on 12 columns; a row is `--spacing-widget-row` (15rem) and the gap `--spacing-lg`, read as pixels from the root at runtime, so widgets on a row are the same height by construction. Vertical compaction fills gaps, so two Piccoli sit in a Medio's width.
- Edit mode (step 65: "Modifica" is the board's own `SplitPill`, top right inside the surface, with "Aggiungi widget" and "Ripristina" as its expanding actions while editing): items drag (whole cell, `.widget-tools` excluded), the content is `inert` at 30% opacity while `.widget-tools` stay at full, a size pill (P/M/G/L, full names as radio labels) sits bottom left and move-before/after (the keyboard path; the library has no keyboard drag) plus remove top right; "Aggiungi widget" focuses the dashed list of missing ones, which adds a widget at its smallest cell area (`smallestWidgetSize`); "Ripristina" resets. Layout animations run only in edit mode (no widgets growing in on load) and never with reduced motion.
- Saved on the server (`layout.get/save/reset`, `desk_layouts`, the `overview` row only: the server refuses any other zone); the client updates the query cache and saves, and drops ids or sizes it does not know. e2e waits for `layout.save` before a reload and for the grid's animations before measuring (`apps/e2e/tests/widgets.spec.ts`).
- `shell/agent-confirmation.tsx` subscribes to pending agent actions: desk uses a dialog, deck a banner. Confirm uses `HoldButton`; dismiss and deny refuse the request. `modules/devices/agents-section.tsx` creates named tokens, shows each token once, lists recent masked calls and revokes with a hold. Copy comes from Paraglide.
- **Activity ball (step 47c).** `shell/activity.tsx` (`ActivityBall`, rendered by `DeskShell`) is a `size-ball` (3.5rem, token) glass ball, a Motion `motion.div` with `drag` (owner 2026-11-14): `top-md left-md z-30` by default, dragged inside a full-window constraint box, the offset kept per device in `localStorage` `hub.ball` (saved on `onDragEnd`, which Motion fires a frame after the release), a double click glides it back; Motion does not swallow the click that ends a drag, so `onClickCapture` does, and the panel opens only on a plain click (`align="start"`), rendered only while something is in progress (no ball, nothing floating, when idle). Items, in this order: Pomodoro (phase not idle: running or paused), each running job, the music track (`media.state.status` Playing or Paused), then module activities. The ring follows the first item with progress: `Arc` in `activity.tsx`, an SVG line (viewBox units, round caps, `pathLength` 100) on the ball's edge, whose glass border is its track; the panel rows draw a `--border` track as well (the earlier conic gradient read as a thick two-tone donut with square ends, owner 2026-11-16); Pomodoro writes its countdown in the middle, otherwise the first item's icon; a count badge shows with more than one item. The accessible name is `Attività in corso: <summaries>` (for example "concentrazione in pausa, 12:30, 1 job, Title"). A click opens a `Popover` (`size="md"`, Escape and outside click close it, `aria-expanded`) listing exactly the items, dashed separators. Each row is one link by the stretched-button pattern (title button `after:inset-0`, accessible name `Apri <title>`, goes to Studio, `/desk/system?tab=jobs`, Media or the module's `href` through `router.history.push`, and closes the panel); its own controls (Pomodoro Riprendi/Pausa, Salta, Ferma; music play/pause and next, the same `RegistryButton`s as elsewhere) are `relative z-10` and act without navigating. The fake player in e2e is always playing or paused, so the ball shows in every baseline of a desk page; `POST /__fake/player {gone}` removes the player for idle checks and `restoreDesktop` brings it back.

- `PageSurface` wraps the plain-page `data-page-scroller` in a rounded clipping frame (`clip-path: inset(0 round var(--radius-xl))`: `overflow: hidden` plus a radius does not cut a child's scrollbar in Chromium, it stayed square over the corners, step 75); the inner scroller reserves the gutter and has a default-width native scrollbar with a transparent track (`thin` was tried; the owner chose the default width, 2026-11-17). Its opaque sticky band includes `TabBarRow` and uses `ResizeObserver` for focus-safe scroll padding. Multi-pane `fill` and `float` pages keep their own scrollers.
- `ZoneTabs` restores tab focus after selection: switching between a plain and a multi-pane tab replaces the band subtree, which would otherwise drop keyboard focus.

- `shell/command-palette.tsx` queries `assistant.state` once on open and appends the assistant for two-word queries when enabled. Its result page lists the action outcomes; the existing agent hold dialog handles danger actions.

- `PageSurface` accepts `dayLine`. `DayLine` on Studio Oggi and Panoramica reads calendar events and enabled modules' `calendarItems`, as well as completed focus; the Panoramica heading also calls each `daySummary` once. Widget context gives `Panel` titles and actions the mono label role; figures use `Readout` and discrete counts use `Ticks`.

- Desk surfaces have no status line (step 91). `day-line-math.ts` packs measured captions in two rows, including adesso; shortened captions retain their full title.
- NumberRoll stacks every digit 0 to 9 in an absolutely placed strip (about 5000 px at hero size): its container must clip (`.instrument-dial` has `overflow: clip`) or a page scroller grows to the strip's height.

- Positioned module deck tiles use indices in the built-in page, before any module insertion. `useDeckPages` inserts higher indices first so an earlier accessory cannot move a later tile ahead of Posta; covered by the private Notizie deck regression.
