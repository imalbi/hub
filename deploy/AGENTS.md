# Desktop integration

- `install.ts` is the CLI; `installer.ts` holds planning, validation and file operations. No runtime dependencies. Tests use temporary config/state directories and an injected command runner; never call the real installer with `--apply` during agent work.
- No `--apply` means no writes, build, service calls or temporary files, including with `--uninstall`. Unknown options fail. Apply builds the web app before changing configuration, then reloads systemd and enables/starts the user service. After updating a running backend, the owner restarts `hub.service`.
- Targets are `systemd/user/hub.service`, `caelestia/hypr-user.lua` and `caelestia/cli.json` under the XDG config directory. Lua uses `-- >>> hub` / `-- <<< hub`; `hypr-user.conf` is never touched. Caelestia supports arbitrary toggle names and handles spawning, moving and toggling the workspace itself.
- The ownership manifest is `hub/desktop-install.json` under the XDG state directory, mode 0600, outside the repo. It saves original/installed text to restore exact bytes when unchanged; reinstall refreshes the originals with unrelated user additions. During writes, `pending` records the previous snapshot so both old and new owned values remain recoverable after interruption; it is cleared after the writes finish. Do not delete the manifest to bypass a conflict.
- Existing unowned units/toggles, changed owned units/toggles, ambiguous Lua markers, and symlink targets are refused. Every changed existing file, including the manifest and files being removed, gets an adjacent timestamped `.hub-backup-*` copy. Backups are retained after uninstall.
- `resolveNode()` follows symlinks and rejects remaining `/run/` or fnm session paths. The unit runs Node directly, uses systemd path escaping and `ExecStart=:` to disable dollar expansion. Config, static files and migrations resolve from their source paths, so no working directory is needed.
- Chrome's observed class is `chrome-127.0.0.1__desk-Default`, initial title `127.0.0.1_/desk`, loaded title `Hub`. Match the class with a variable profile suffix plus the initial title; re-measure after Chrome changes. Validate Lua with `luac -p`; validate a rendered unit in a temporary file with `systemd-analyze --user --generators=no --man=no verify`.
